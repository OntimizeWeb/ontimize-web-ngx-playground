The simulated DELETE fails

There is no o-form and no FormGroup on this page: the editor is driven only by [(ngModel)], and the JSON at the bottom is the model itself. Removing a group goes through remove-group-handler, an async handler that takes ~1.5s: the row keeps its place showing a skeleton while the call is pending, and when the handler resolves false (or throws) the row comes back untouched. Groups and items are draggable by default (groups-draggable / items-draggable); the up/down arrow buttons on every row are the keyboard alternative, since cdk drag & drop provides none.
